Get started

Install the kernel

A kernelspec belongs to the machine, so the usual choice is to install juphyter once for your user, as Installation describes. Installing it as a development dependency of one project pins the kernel’s version with that project, at the cost of a kernelspec that names that project’s copy of the engine:

composer require --dev phpstats/juphyter
vendor/bin/juphyter install

The command prints what the kernel is made of.

Installed the juphyter kernel "php" for PHP 8.5.10.
  kernel.json  /Users/you/Library/Jupyter/kernels/php/kernel.json
  python       /opt/homebrew/bin/python3 (ipykernel 7.4.0)
  php          /opt/homebrew/bin/php
  engine       /path/to/vendor/phpstats/juphyter/bin/juphyter
  quarto       /opt/homebrew/bin/python3 (jupyter_client 8.10.0)

The Python is the interpreter that owns the jupyter on PATH, because the kernel runs inside it. --python names a different one. The PHP is the binary that runs the cells, and --php names a different one, which is how several versions coexist:

vendor/bin/juphyter install --name php83 --php /opt/homebrew/opt/php@8.3/bin/php
vendor/bin/juphyter install --name php85 --php /opt/homebrew/opt/php@8.5/bin/php

juphyter uninstall --name php83 removes a kernelspec juphyter wrote, and refuses to remove one it did not.

The quarto line appears when Quarto is installed. Quarto runs an interpreter of its own choosing, and that one is the one that needs Jupyter in it, so the line reports which interpreter that is and what was found there. When it says (no Jupyter), the kernelspec is still correct and quarto render cannot reach it; Installation covers the fix.

On a machine with no Python that can host the kernel at all, the command offers to build one. Installation covers that and the --create-venv option that answers the offer in advance.

A first cell

A cell is PHP without an opening tag. The value of the last expression is the cell’s result, and echo goes to the cell’s output stream.

$primes = [2, 3, 5, 7, 11, 13];

echo count($primes), " primes, summing to ", array_sum($primes), "\n";

array_sum($primes) / count($primes);
6 primes, summing to 41
6.833333333333333

State carries between cells, so the next cell sees what this one bound.

$primes[] = 17;

$primes;
[2, 3, 5, 7, 11, 13, 17]

Imports

A use statement applies to the cells after it as well as to its own. The session accumulates them, so a notebook can put its imports in a first cell and use short class names from then on.

use DateTimeImmutable;

$released = new DateTimeImmutable('2026-11-20');

$released->format('F Y');
Warning: The use statement with non-compound name 'DateTimeImmutable' has no effect in Cell 3, line 0
'November 2026'

namespace is not supported in a cell, and a cell cannot redeclare a class or a function that another cell already declared. PHP has no way to undefine either, so a second run of a cell that declares one reports what it would have redeclared rather than failing in the middle.

Errors

A cell that throws reports the exception, its message, and the stack frames that raised it, with each stack frame naming the cell and the line rather than eval()'d code.

$widths = ['narrow' => 4, 'wide' => 12];

$mean = fn (array $values) => array_sum($values) / count($values);

$mean([]);
Warning: The use statement with non-compound name 'DateTimeImmutable' has no effect in Cell 4, line 0
DivisionByZeroError: Division by zero
DivisionByZeroError: Division by zero
  in a closure
  at Cell 4, line 5

Warnings, notices, and deprecations go to the cell’s error stream and leave the cell running.

$widths = ['narrow' => 4, 'wide' => 12];

$widths['narrow'] + $widths['medium'];
Warning: The use statement with non-compound name 'DateTimeImmutable' has no effect in Cell 5, line 0
Warning: Undefined array key "medium" in Cell 5, line 3
4

Rich display

A value is published in every representation the front end might draw. A phibble data frame comes with an HTML table and the tibble-style text phibble prints at a terminal, and a phiz plot comes with a Vega-Lite specification, an HTML embed, a static SVG when vl-convert is installed, and a one-line description.

Warning: The use statement with non-compound name 'DateTimeImmutable' has no effect in Cell 6, line -1
DataFrame::fromRows([
    ['package' => 'phibble', 'purpose' => 'data frames', 'version' => 0.3],
    ['package' => 'phplyr', 'purpose' => 'dplyr verbs', 'version' => 0.3],
    ['package' => 'phiz', 'purpose' => 'plots', 'version' => 0.3],
]);
Warning: The use statement with non-compound name 'DateTimeImmutable' has no effect in Cell 7, line -1
A tibble: 3 × 3
package <chr> purpose <chr> version <dbl>
1 phibble data frames 0.3
2 phplyr dplyr verbs 0.3
3 phiz plots 0.3

Any class can opt in. A toHtml(): string method supplies the text/html representation, and a toMimeBundle(): array method supplies the whole bundle.

final class Progress
{
    public function __construct(private readonly int $done, private readonly int $total) {}

    public function toHtml(): string
    {
        return sprintf(
            '<progress value="%d" max="%d"></progress> %d of %d',
            $this->done,
            $this->total,
            $this->done,
            $this->total,
        );
    }

    public function __toString(): string
    {
        return sprintf('%d of %d', $this->done, $this->total);
    }
}

new Progress(7, 9);
Warning: The use statement with non-compound name 'DateTimeImmutable' has no effect in Cell 8, line -1
7 of 9

Juphyter\display() publishes a value part way through a cell, so one cell can show several data frames or plots.

Juphyter\display(new Progress(3, 9));
Juphyter\display(new Progress(9, 9));
Warning: The use statement with non-compound name 'DateTimeImmutable' has no effect in Cell 9, line -1
3 of 9
9 of 9
