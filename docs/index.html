juphyter

A Jupyter and Quarto kernel for PHP

Run PHP in Jupyter notebooks and Quarto documents, with tables and charts displayed alongside code.

A notebook is a file of cells, each holding a few lines of code with its output beneath it. The program that runs the cells is a kernel. juphyter is a kernel for PHP, and it keeps one PHP session open, so a variable set in one cell is available in the next.

  • JupyterLab: after juphyter install, JupyterLab lists PHP in its launcher. See JupyterLab.
  • Quarto: a .qmd that names jupyter: php in its front matter renders its {php} cells to HTML, PDF, or Word. See Quarto.

What a cell shows

The value of a cell’s last expression is its output. A phibble data frame appears as an HTML table with its dimensions and column types, and a phiz plot appears as a chart. Other values appear as a compact dump.

The examples below use phibble, phplyr, and phiz. In a Composer project, install them with the command below. The php kernel then loads the project’s vendor/autoload.php for any notebook or document inside the project. The phpstats packages covers using them outside a project.

composer require phpstats/phibble phpstats/phplyr phpstats/phiz

The examples read mtcars from the phpstats datasets repository: fuel economy and design measures of 32 cars from R’s datasets package. phplyr’s round() replaces PHP’s built-in round() in the cells after this import.

use function Phplyr\{phplyr, group_by, summarize, arrange, desc, n, mean, round};
  • PHP 8.5+
  • PHP 8.3–8.4
$mtcars = \Phibble\DataFrame::fromCsv(
    'https://raw.githubusercontent.com/'
    .'phpstats/datasets/main/csv/mtcars.csv'
);

$mtcars |>
    group_by('gear') |>
    summarize(cars: n(), mpg: round(mean('mpg'), 1)) |>
    arrange(desc('mpg'));
A tibble: 3 × 3
gear <int> cars <int> mpg <dbl>
1 4 12 24.5
2 5 5 21.4
3 3 15 16.1 
$mtcars = \Phibble\DataFrame::fromCsv(
    'https://raw.githubusercontent.com/'
    .'phpstats/datasets/main/csv/mtcars.csv'
);

phplyr($mtcars)
    ->groupBy('gear')
    ->summarize(cars: n(), mpg: round(mean('mpg'), 1))
    ->arrange(desc('mpg'))
    ->get();
A tibble: 3 × 3
gear <int> cars <int> mpg <dbl>
1 4 12 24.5

3 3 15 16.1 
\Phiz\Plot::of($mtcars)
    ->aes(x: 'wt', y: 'mpg')
    ->point()
    ->smooth(method: 'lm')
    ->labs(x: 'Weight (1,000 lb)', y: 'Miles per gallon');

Fuel economy against weight, with a least-squares line.

What the kernel provides

  • State across cells, including use imports and declared functions and classes.
  • Tracebacks that name the cell and the line, instead of eval()'d code.
  • HTML tables for phibble data frames and charts for phiz plots, plus toHtml() and toMimeBundle() hooks for any other class.
  • Juphyter\display(), which shows a value part way through a cell.
  • Completion of variables, functions, classes, and members.
  • Interrupting a running cell with the stop button, when PHP has the pcntl extension.
  • Loading the nearest vendor/autoload.php above the notebook, so a notebook inside a Composer project can use that project’s classes and packages.

juphyter requires none of the phpstats packages. It runs plain PHP, and it formats a phibble data frame or a phiz plot when those packages are installed.

How it works

A Python program built on ipykernel handles the Jupyter protocol, and a PHP process runs the cells. They talk over a Unix socket. That is why an install needs Python as well as PHP, and why the kernel runs on macOS and Linux only.
